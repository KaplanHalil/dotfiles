GITHUB SYNC - SORUN COZME REHBERI
=================================

Gunluk GitHub senkronizasyonu tikandiginda asagidaki adimlari izleyin.
Sorunlu repolar genelde ~/GitHub/ altindadir, ornegin: ~/GitHub/RAG_crypto

ADIM 0 - Durumu gorun
    cd ~/GitHub/<repo>
    git status

ADIM 1 - Yerel degisikliklerin var ama push yapmak istemiyorsun (en guvenlisi)
    Buradaki calisman korunur, ileri degisiklikler cekilir:
    git stash
    git pull --ff-only
    git stash pop
    Not: stash pop'ta cakisma olursa git dosyalari "Cakisma" isaretine gore
    birlestirmeni ister - dosyalari acip el ile duzelt, sonra:
    git add <duzeltilen dosyalar>
    git stash drop

ADIM 2 - Yerel degisiklikleri commit edip pushlamak istiyorsun
    HASSAS dosya var mi kontrol et (sifre, token, .env gibi):
    git status
    git add -A
    git commit -m "guncelleme: <ne yaptigin>"
    git push

ADIM 3 - Commit ettin ama push yapamadin (gecmis yaristi)
    git pull --rebase
    git push

ADIM 4 - Pull/push ag hatasi veriyor
    Ag baglantini kontrol et, sonra:
    ssh -T git@github.com
    "Permission denied (publickey)" cikarsa anahtar yuklenmemis demektir:
    cat ~/.ssh/id_ed25519.pub  ->  https://github.com/settings/ssh/new
    Sadece senin repolarin senkronize edilir; yabanci repolarda remote degistirme.

DOTFILES (bu repo) - TIMER BASARISIZ
------------------------------------
Zamanlayici ("systemctl --user list-timers dotfiles-backup") su durumlarda
push yapamaz; ekranda soru soramaz, bu yuzden hemen hata verir:

 1) SSH anahtari parola soruyor
    Zamanlayici parola soramaz. Anahtarin parolasiz olmasi gerekir:
        ssh-keygen -p -f ~/.ssh/id_ed25519   ->  eski bos, yeni bos
    Parolasiz anahtar SADECE bu bilgisayarda guvenlidir; kendin karar ver.

 2) "~/.ssh/id_ed25519.pub" degistiyse
    Yeni public key'i GitHub'a ekle: https://github.com/settings/ssh/new

 3) Push reddediliyor (non-fast-forward)
    Baska bir makine (home <-> tbtk) ayni dosyayi degistirmis:
        cd ~/.dotfiles
        git pull --rebase
        git push
    Konflikt cikarsa dosyalari elle duzelt, sonra:
        git add <duzeltilenler> && git rebase --continue

 4) Ne oldugunu gor
        journalctl --user -u dotfiles-backup -n 40

 5) Ekranin kilitliyken / uyku modundayken timer calisir
    Gecmis bir calistirmayi doldurmak icin Persistent=true ayarli;
    "last" zamanini kontrol et:
        systemctl --user list-timers dotfiles-backup

PAKET TIERLARI
--------------
install-packages.sh YALNIZCA ~/.dotfiles-host-id'de yazan makinenin
tier'ini okur. Yanlislikla:
    "home" -> oyunlar (steam, lutris, wine) SADECE ev bilgisayarinda
    "tbtk" -> nvidia/intel suruculer SADECE is bilgisayarinda
Baska bir makinenin tier'i hicbir zaman okunmaz.
Kendi turunu gormek icin:
    ~/.dotfiles/install-packages.sh --host <id> --dry-run

GENEL KURALLAR
- sync-github-repos.sh SADECE ceker (pull), yerel degisikliklere el surmez.
- Asla sunlari calistirma (veri kaybi):
      git reset --hard
      git checkout -- .
      git clean -fdx
- Emin degilsen once bir yedek al:
      cp -r ~/GitHub/<repo> /tmp/<repo>.yedek
- ~/.dotfiles altındaki degisiklikler omarchy config'ini ETKILEMEZ.
  Etkilemek icin: omarchy restart shell && hyprctl reload
